# calc.

A precision calculator with a clean, hardware-inspired interface.

🔗 **Live Demo:** _(add your deployed link here)_


# ✨ Features

- Standard operations: add, subtract, multiply, divide
- Percentage and sign toggle (+/−)
- Operation history shown above the display
- Full keyboard support (numbers, operators, Enter, Backspace, Esc)
- Division-by-zero handling
- Responsive down to mobile screens

---

## 🧩 Tech Stack

Pure HTML, CSS, and JavaScript — no frameworks, no dependencies.

--

## 🚀 Getting Started

```bash
git clone https://github.com/jahongir-stack/calc.git
cd calc
```

Open `index.html` in any browser — no build step required.
